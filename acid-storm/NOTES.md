# טבעת חומצה - הערות מסירה (16.10.2026)

קרא את הקובץ הזה לפני כל שינוי בקוד. הכל יושב ב-index.html אחד (+ sw.js לאופליין).

## מבנה הצליל (מגרסה זו)

- **ליבת DSP ב-AudioWorklet** ("acid-core"): הקוד שלה יושב כמחרוזת `CORE_SRC` בתוך index.html, נטען דרך Blob URL (ואם זה נכשל, דרך data: URL). אם אין AudioWorklet בכלל, האפליקציה נופלת למסלול הישן (BiquadFilter) בלי שינוי בממשק. `E.wk` הוא ה-AudioWorkletNode, `E.wk===null` = מסלול ישן.
- קלטים לליבה: 0 = ערבוב האוסילטורים (gA/gB, PeriodicWave), 1 = סאב. פלט: ערוץ 0 = בס אחרי מסנן ו-VCA, ערוץ 1 = סאב אחרי VCA. ChannelSplitter מפריד אותם.
- בתוך הליבה: מעטפת VCA, מעטפת מסנן (fenv), מצבר הדגשה (acc, נטען בהדגשות צמודות, דועך ב-0.45 שניות), ושני מסננים A (עולם עומק) ו-B (עולם חומצה) עם מעבר (morph). ארבעת האופיים: 0 חם = סולם 4 קטבים TPT עם tanh בכל שלב (השמעה עצמית מעל ~res 0.9), 1 חלול = SVF פס, 2 מדבר = שלושה SVF פורמנטים, 3 מתכת = מסרק בגובה התו. הכל בדגימת-יתר פי 2.
- החלפת אופי = פרמטר ftA/ftB (אינדקס ב-FTYPES); הליבה עושה crossfade של 30ms בעצמה. כששני האופיים זהים ו-morph=0 רץ מסנן אחד בלבד.
- הודעות לליבה: `{type:"note",t,id,f,acc,leg}`, `{type:"off",t,id}` (מתעלם אם id לא תואם לתו הנוכחי), `{type:"kill"}`. הזמנים הם ctx.currentTime, הליבה מיישמת לפי דגימה.
- פרמטרים (k-rate): cut (Hz, כולל הסלמה), res, env (אוקטבות), dec (שניות), sat (רוויה בתוך המסנן: לכלוך + החזקת המרכז), morph.
- אחרי הליבה: עיוות tanh (pre/post, עדין יותר מבעבר), highpass 28Hz, באס. הד פינג-פונג סטריאו (dl -> dlR -> dl, LFO 0.23Hz על זמן ההשהיה), ריוורב ConvolverNode עם IR מחושב (`makeIR`, 1.35s, מתכהה), קומפרסור, קליפ רך.
- ידית חדשה בעולם: "מרחב" (rev). ידית חדשה בכרטיס התחתון: "סווינג" (S.swing, גלובלי, נשמר גם בזיכרונות).

## דברים שחשוב לדעת

- `makeEngine` הוא async; `ensureAudio` מחכה ל-`engP`. אל תשתמש ב-E לפני ש-ensureAudio חזר true.
- סווינג: כל צעד אי-זוגי מתאחר ב-`swing*stepDur*0.36`. אורך השער של כל תו מחושב לפי המרווח האמיתי לצעד הבא (gap), אחרת ה-off היה "הורג" את התו הבא.
- שם התו מוצג במרכז הטבעת בזמן גרירה (`dragLabel`, `noteName`).
- NOTES ו-degMidi מוגדרים ליד SCALES (הועלו למעלה).
- sw.js: CACHE="acid-v5". לבאמפ בכל העלאה.
- נבדק רק ב-Node (סימולציה של הליבה + jsdom לדף). חובה בדיקה על אייפון/אייפד.
