`index.html` בשורש הוא **העמוד הראשי של רז**: הכל מסודר **לפי מכשיר** (הטי־8, הוולקות, כלים במסך, עזרים), ובתוך הטי־8 לפי סדר הלימוד: מתחילים, מנגנים, טריקים, לעיון. מי בנה מופיע כתגית בכל כרטיס. רז שומר את הקישור הזה במסך הבית.

- **כל דבר חדש באתר מקבל כרטיס בעמוד הראשי**, באותו commit, במכשיר ובקבוצה המתאימים: `<a class="item">` עם `data-who` (`claude`, `grok`, `codex`, `raz`, כמה מופרדים ברווח), ואותן תוויות `.who` בתוך הכרטיס. ההוראות גם בהערה בראש הקובץ.
- **חיפוש:** החיפוש בראש העמוד קורא בזמן אמת את כל העמודים שברשימה `PAGES` בתוך הסקריפט: כותרות, כרטיסים עם `id` ושאלות התרגול. כרטיס חדש בעמוד קיים נמצא לבד, בתנאי שיש לו `id` וכותרת. **עמוד חדש צריך להיכנס ל־`PAGES`.**
- גרסה חדשה של משהו קיים: התווית ״החדשה״ עוברת אליה, והישנה נשארת ברשימה.
- לא מוסיפים service worker לעמוד הראשי: הוא אמור להיטען תמיד מהרשת, כדי שכל עדכון יופיע מיד.

## כללי עבודה משותפת

- לפני כל שינוי: `git pull`. אחרי השינוי: commit ו־push מיד.
- כל מודל עובד בתיקייה שלו. לא משנים קבצים בתיקייה של השני.
- רוצים להציע שינוי לגרסה של השני? כותבים אותו ל־`NOTES.md` בשורש, ורז מעביר.

## גרסת קלוד

התוכן נמצא ב־`claude/src/`. הדפים נבנים עם `python3 claude/build.py`, ואת `lesson-*.html` ו־`index.html` שבתיקייה לא עורכים ידנית.
לפני כל עבודה על `claude/` קוראים את `claude/HANDOFF.md`: המבנה, ההחלטות, מה מחכה לבדיקה, ואיך בודקים לפני push.

## מכונת אווירות

אפליקציה עצמאית, בתיקייה `synth/`, בכתובת משלה ובלי קישורים לשיעורים. אין שלב בנייה: עורכים ישירות את `engine.js` (הצליל), `app.js` (הממשק) ו־`style.css`.
כשמשנים קבצים, מעלים את מספר הגרסה ב־`CACHE` שב־`sw.js`, כדי שמכשירים שהתקינו את האפליקציה יקבלו את העדכון.

## Codex introduction

Edit `codex/src/t8-intro.html`, then run `python codex/build.py`. It builds `codex/index.html` and the Codex diagrams declared in `codex/src/figures.json`. The six chapter HTML fragments in `codex/src/` are included in order. See `codex/PROJECT.md`. Shared lesson CSS/JS and existing diagrams are reused from `claude/` without editing that directory. Raz approved the full lesson on 2026-10-19; its public URL remains `codex/`.
