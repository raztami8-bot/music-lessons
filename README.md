# שיעורי מוזיקה

אתר השיעורים של רז. יש בו שתי גרסאות, ושני מודלים עובדים עליו.

| גרסה | תיקייה | מי עובד עליה |
| --- | --- | --- |
| גרסת גרוק | `lessons/` | גרוק |
| גרסת קלוד | `claude/` | קלוד |

`index.html` בשורש הוא עמוד משותף שמקשר לשתי הגרסאות. כל מודל משנה בו רק את החלק של הגרסה שלו.

## כללי עבודה משותפת

- לפני כל שינוי: `git pull`. אחרי השינוי: commit ו־push מיד.
- כל מודל עובד בתיקייה שלו. לא משנים קבצים בתיקייה של השני.
- רוצים להציע שינוי לגרסה של השני? כותבים אותו ל־`NOTES.md` בשורש, ורז מעביר.

## גרסת קלוד

התוכן נמצא ב־`claude/src/`. הדפים נבנים עם `python3 claude/build.py`, ואת `lesson-*.html` ו־`index.html` שבתיקייה לא עורכים ידנית.
