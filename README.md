`index.html` בשורש הוא **העמוד הראשי של רז**: רשימה אחת של כל השיעורים, המדריכים והכלים, ולכל אחד מי בנה אותו, מה הוא, ושורה על מה הוא. רז שומר את הקישור הזה במסך הבית.

- **כל דבר חדש באתר מקבל כרטיס בעמוד הראשי**, באותו commit: `<a class="item">` בקבוצה המתאימה, עם `data-type` (`lesson`, `guide` או `tool`) ו־`data-who` (`claude`, `grok`, `codex`, `raz`, כמה מופרדים ברווח), ואותן תוויות בתוך הכרטיס. ההוראות גם בהערה בראש הקובץ.
- גרסה חדשה של משהו קיים: התווית ״החדשה״ עוברת אליה, והישנה נשארת ברשימה.
- לא מוסיפים service worker לעמוד הראשי: הוא אמור להיטען תמיד מהרשת, כדי שכל עדכון יופיע מיד.
- `kitchen/` לא מופיע בעמוד הראשי, לבקשת רז.

## כללי עבודה משותפת

- לפני כל שינוי: `git pull`. אחרי השינוי: commit ו־push מיד.
- כל מודל עובד בתיקייה שלו. לא משנים קבצים בתיקייה של השני.
- רוצים להציע שינוי לגרסה של השני? כותבים אותו ל־`NOTES.md` בשורש, ורז מעביר.

## גרסת קלוד

התוכן נמצא ב־`claude/src/`. הדפים נבנים עם `python3 claude/build.py`, ואת `lesson-*.html` ו־`index.html` שבתיקייה לא עורכים ידנית.

## מכונת אווירות

אפליקציה עצמאית, בתיקייה `synth/`, בכתובת משלה ובלי קישורים לשיעורים. אין שלב בנייה: עורכים ישירות את `engine.js` (הצליל), `app.js` (הממשק) ו־`style.css`.
כשמשנים קבצים, מעלים את מספר הגרסה ב־`CACHE` שב־`sw.js`, כדי שמכשירים שהתקינו את האפליקציה יקבלו את העדכון.

## המטבח

אפליקציה עצמאית בתיקייה `kitchen/`. הרעיון, ההחלטות, ההוראות לעדכון ויומן הגרסאות נמצאים ב־`kitchen/PROJECT.md`. קוראים אותו לפני כל שינוי, ומוסיפים בו שורה אחרי כל שינוי.

## Codex introduction

Edit `codex/src/t8-intro.html`, then run `python codex/build.py`. It builds only `codex/index.html`. Shared lesson CSS/JS and existing diagrams are reused from `claude/` without editing that directory. Publish only the first excerpt until Raz approves continuing the lesson.
